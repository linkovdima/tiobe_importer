# 🔧 Исправление проблемы с источниками C++

## Проблема
В онтологии отсутствуют источники для языка C++ (CPlusPlus).

## Решение

Запустите скрипт для добавления источников C++:

```bash
python add_russian_sources.py
```

Или если у вас Python установлен как `py`:

```bash
py add_russian_sources.py
```

Этот скрипт добавит источники для всех языков, включая C++:
- 4 книги
- 3 документации  
- 2 туториала

**Всего для C++ будет добавлено 9 источников.**

## Проверка

После запуска скрипта проверьте результат:

```bash
python check_sources.py
```

Или откройте в браузере:
- http://localhost:5000/language/CPlusPlus/sources

## Альтернативный способ

Если скрипт `add_russian_sources.py` не работает, можно использовать:

```bash
python fix_cpp_sources.py
```

Этот скрипт добавит только источники для C++.

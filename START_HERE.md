# 🚀 Начните здесь - Инструкция по запуску

## Шаг 1: Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

Это установит все необходимые библиотеки:
- requests, beautifulsoup4 - для парсинга и HTTP запросов
- rdflib - для работы с онтологией
- flask - для веб-интерфейса
- matplotlib - для графиков
- schedule - для автоматических обновлений

## Шаг 2: Настройка GitHub токена (опционально, но рекомендуется)

1. Создайте файл `github_config.py` (если его еще нет)
2. Получите токен на https://github.com/settings/tokens
3. Добавьте в файл:
   ```python
   GITHUB_TOKEN = "ваш_токен_здесь"
   ```

**Зачем это нужно?**
- Без токена: 60 запросов/час к GitHub API
- С токеном: 5000 запросов/час

## Шаг 3: Проверка онтологии

Убедитесь, что файл онтологии существует:
```
data/programming_languages.ttl
```

Если файла нет, система создаст его при первом запуске.

## Шаг 4: Первый запуск - Обновление данных

### Вариант А: Однократное обновление (рекомендуется для начала)

```bash
python main.py update
```

Это:
- ✅ Получит данные из TIOBE, GitHub, Stack Overflow
- ✅ Обновит онтологию
- ✅ Сохранит результаты в лог

### Вариант Б: Интерактивный режим

```bash
python main.py
```

Выберите:
1. Однократное обновление
2. Запуск по расписанию
3. Тестовый режим (демо-данные)

### Вариант В: Тестовый режим (быстрый старт)

```bash
python main.py test
```

Использует демо-данные, не требует интернета.

## 🎯 Типичный рабочий процесс

### Первый запуск (один раз)
1. `pip install -r requirements.txt`
2. Создайте `github_config.py` с токеном
3. `python main.py update` - обновите данные
4. `python web_dashboard.py` - запустите веб-интерфейс

### Ежедневная работа
1. `python web_dashboard.py` - запустите веб-интерфейс
2. Откройте http://localhost:5000/search
3. Используйте поиск по онтологии

### Регулярное обновление данных
- **Вручную**: `python main.py update` (раз в неделю/месяц)
- **Автоматически**: `python main.py schedule` (запускается по расписанию)

## 🔧 Решение проблем

### Проблема: Парсер получает числа вместо названий языков
**Симптомы:**
```
⚠️ Не распознано: 1 (оригинал: 1)
⚠️ Не распознано: 2 (оригинал: 2)
```

**Решение**: 
1. Запустите тестовый скрипт для диагностики:
   ```bash
   python test_tiobe_parsing.py
   ```
2. Система автоматически использует демо-данные, если парсинг не работает
3. Для работы используйте тестовый режим: `python main.py test`

### Проблема: "ModuleNotFoundError"
**Решение**: Установите зависимости
```bash
pip install -r requirements.txt
```

### Проблема: "Файл онтологии не найден"
**Решение**: Убедитесь, что файл `data/programming_languages.ttl` существует

### Проблема: "Rate limit exceeded" для GitHub
**Решение**: Добавьте токен в `github_config.py`

### Проблема: Порт 5000 занят
**Решение**: Измените порт в `web_dashboard.py`:
```python
app.run(debug=True, host='0.0.0.0', port=5001)  # Используйте другой порт
```

### Проблема: Данные не обновляются
**Решение**: 
1. Проверьте интернет соединение
2. Проверьте логи в консоли
3. Попробуйте тестовый режим: `python main.py test`
4. Запустите диагностику: `python test_tiobe_parsing.py`

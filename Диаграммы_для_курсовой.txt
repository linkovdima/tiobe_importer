ИНСТРУКЦИИ ПО СОЗДАНИЮ ДИАГРАММ
================================================================================

Для создания диаграмм рекомендуется использовать следующие инструменты:

1. Draw.io (diagrams.net) - бесплатный онлайн-редактор диаграмм
   URL: https://app.diagrams.net/
   - Поддерживает UML, ER-диаграммы, блок-схемы
   - Экспорт в PNG, PDF, SVG
   - Интеграция с Google Drive, OneDrive

2. Lucidchart - профессиональный инструмент для создания диаграмм
   URL: https://www.lucidchart.com/
   - Шаблоны для различных типов диаграмм
   - Совместная работа
   - Экспорт в различные форматы

3. PlantUML - текстовое описание диаграмм
   URL: http://www.plantuml.com/
   - Код для диаграмм можно включить в документ
   - Автоматическая генерация диаграмм

4. Microsoft Visio - для пользователей Windows
   - Профессиональные инструменты
   - Интеграция с Office

5. yEd Graph Editor - бесплатное приложение
   URL: https://www.yworks.com/products/yed
   - Мощные возможности автоматического размещения
   - Поддержка различных форматов

Рекомендации по оформлению:

- Использовать единый стиль для всех диаграмм
- Добавить подписи и легенды
- Убедиться, что текст читаем
- Использовать контрастные цвета
- Добавить нумерацию диаграмм
- Включить описание каждой диаграммы в тексте работы

# Примеры поисковых запросов

## 🔍 Что можно искать в системе поиска

Система поиска позволяет находить информацию по ключевым словам в:
- Названиях публикаций (книги, статьи)
- Ключевых словах публикаций
- Свойствах языков программирования
- Фреймворках

## 📚 Примеры поисковых запросов

### По названиям языков

**"Python"** - найдет:
- Все публикации о Python
- Информацию о языке Python
- Книги, статьи, документацию по Python

**"Java"** - найдет:
- Все материалы о Java
- Книги по Java
- Документацию Java

### По типам материалов

**"книга"** или **"book"** - найдет все книги

**"документация"** или **"documentation"** - найдет всю документацию

**"туториал"** или **"tutorial"** - найдет все туториалы

**"статья"** или **"article"** - найдет все статьи

### По тематике

**"web development"** или **"веб разработка"** - найдет:
- Языки для веб-разработки (JavaScript, Python)
- Фреймворки для веб-разработки
- Публикации о веб-разработке

**"object oriented"** или **"объектно-ориентированный"** - найдет:
- Языки с ООП парадигмой (Java, Python, C++)
- Публикации об ООП

**"beginner"** или **"начинающий"** - найдет:
- Материалы для начинающих
- Книги для новичков
- Туториалы для старта

**"advanced"** или **"продвинутый"** - найдет:
- Продвинутые материалы
- Книги для опытных разработчиков

### По конкретным книгам

**"Fluent Python"** - найдет книгу "Fluent Python"

**"Effective Java"** - найдет книгу "Effective Java"

**"You Don't Know JS"** - найдет серию книг о JavaScript

### По авторам

**"Luciano Ramalho"** - найдет книги этого автора

**"Joshua Bloch"** - найдет книги этого автора

### По русским источникам

**"русский"** или **"russian"** - найдет все русскоязычные источники

**"на русском"** - найдет материалы на русском языке

**"учебник"** - найдет учебники (часто русскоязычные)

### По фреймворкам

**"Django"** - найдет информацию о Django (Python фреймворк)

**"React"** - найдет информацию о React (JavaScript фреймворк)

**"Spring"** - найдет информацию о Spring (Java фреймворк)

### Комбинированные запросы

**"Python книга"** - найдет книги по Python

**"Java документация"** - найдет документацию по Java

**"JavaScript туториал"** - найдет туториалы по JavaScript

**"C++ для начинающих"** - найдет материалы для новичков по C++

## 🎯 Советы по поиску

### 1. Используйте фильтры по языкам

После ввода запроса выберите конкретный язык в фильтрах, чтобы сузить результаты:
- Выберите "Python" для поиска только по Python
- Выберите "JavaScript" для поиска только по JavaScript

### 2. Комбинируйте ключевые слова

- **"Python advanced"** - продвинутые материалы по Python
- **"Java beginner"** - материалы для начинающих по Java
- **"JavaScript web"** - веб-разработка на JavaScript

### 3. Поиск по части названия

- **"fluent"** - найдет "Fluent Python"
- **"effective"** - найдет "Effective Java", "Effective Python", "Effective Modern C++"
- **"crash course"** - найдет книги типа "Crash Course"

### 4. Поиск по темам

- **"machine learning"** - машинное обучение
- **"data science"** - наука о данных
- **"game development"** - разработка игр
- **"mobile development"** - мобильная разработка

## 📊 Что показывается в результатах

Каждый результат содержит:
- **Тип** (язык, публикация, фреймворк)
- **Название**
- **Автор** (для книг)
- **Ключевые слова**
- **Релевантность** (процент совпадения)
- **Ссылки** (если есть)

## 🔗 Полезные ссылки

- **Все источники для языка**: `/language/Python/sources`
- **Поиск**: `/search`
- **Дашборд**: `/dashboard`
- **Список языков**: `/languages`

## 💡 Примеры реальных запросов

1. **"python книга русский"** - найдет русские книги по Python
2. **"javascript документация"** - найдет документацию по JavaScript
3. **"java обучение"** - найдет материалы для обучения Java
4. **"c++ справочник"** - найдет справочники по C++
5. **"web development python javascript"** - найдет материалы о веб-разработке

## 🚀 Быстрый старт

1. Откройте http://localhost:5000/search
2. Введите ключевые слова
3. При необходимости выберите язык
4. Нажмите "Найти"
5. Просмотрите результаты, отсортированные по релевантности

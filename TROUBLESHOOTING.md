# Решение проблем

## Проблема: Ошибка установки pandas

**Симптомы:**
```
ERROR: Failed building wheel for pandas
```

**Решение:**
Pandas был удален из зависимостей, так как не используется в проекте. Просто установите зависимости заново:

```bash
pip install -r requirements.txt
```

Если ошибка сохраняется, установите зависимости по одной:
```bash
pip install requests beautifulsoup4 lxml rdflib schedule flask matplotlib
```

## Проблема: Фильтр не находит языки (0 из 6)

**Симптомы:**
```
✅ Получено 20 рейтингов с TIOBE
🎯 Фильтр: оставлено 0 из 6 целевых языков
```

**Причина:**
Названия языков из TIOBE могут отличаться от ожидаемых (например, "C++" вместо "CPlusPlus").

**Решение:**
Логика фильтрации была улучшена. Теперь система:
1. Проверяет различные варианты названий
2. Выводит отладочную информацию о полученных языках
3. Автоматически нормализует названия

**Что делать:**
1. Запустите обновление снова: `python main.py update`
2. Проверьте вывод - теперь будут показаны все полученные языки
3. Если проблема сохраняется, проверьте логи и сообщите о проблеме

## Проблема: Rate limit для GitHub API

**Симптомы:**
```
⚠️ Rate limit для GitHub API
```

**Решение:**
1. Создайте файл `github_config.py`
2. Получите токен на https://github.com/settings/tokens
3. Добавьте в файл:
   ```python
   GITHUB_TOKEN = "ваш_токен_здесь"
   ```

## Проблема: Онтология не загружается

**Симптомы:**
```
❌ Файл онтологии не найден
```

**Решение:**
1. Убедитесь, что файл `data/programming_languages.ttl` существует
2. Если файла нет, запустите обновление - он будет создан автоматически
3. Проверьте права доступа к папке `data`

## Проблема: Веб-интерфейс не запускается

**Симптомы:**
```
Address already in use
```

**Решение:**
Порт 5000 занят. Измените порт в `web_dashboard.py`:
```python
app.run(debug=True, host='0.0.0.0', port=5001)  # Используйте другой порт
```

## Проблема: Данные не обновляются

## Проблема: Импорты не работают

**Симптомы:**
```
ModuleNotFoundError: No module named 'xxx'
```

**Решение:**
1. Установите зависимости: `pip install -r requirements.txt`
2. Убедитесь, что используете правильную версию Python (3.8+)
3. Проверьте, что находитесь в правильной директории

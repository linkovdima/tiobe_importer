# Руководство по использованию поиска по онтологии

## Обзор

Система поиска позволяет находить информацию о языках программирования, публикациях, фреймворках и других сущностях в онтологии по ключевым словам.

## Возможности поиска

### 1. Поиск по ключевым словам
- Поиск в названиях публикаций (книги, статьи)
- Поиск в ключевых словах публикаций
- Поиск в свойствах языков программирования (создатель, парадигмы, домены применения, фреймворки, система типов, кривая обучения)
- Поиск в фреймворках

### 2. Фильтрация по языкам
- Можно выбрать конкретные языки для поиска
- Можно искать по всем языкам сразу

### 3. Типы результатов
- **Языки программирования** - полная информация о языке с рейтингами TIOBE, GitHub, Stack Overflow
- **Публикации** - книги и статьи с ключевыми словами и авторами
- **Фреймворки** - фреймворки и связанные с ними языки

## Использование веб-интерфейса

1. Откройте страницу `/search` в браузере
2. Введите ключевые слова в поле поиска (например: "web development", "object oriented", "beginner")
3. При необходимости выберите языки для фильтрации
4. Нажмите "Найти"
5. Просмотрите результаты, отсортированные по релевантности

## Использование API

### Поиск по ключевым словам

**POST** `/api/search`

```json
{
  "keywords": "web development",
  "languages": ["Python", "JavaScript"]  // опционально, null для всех языков
}
```

**Ответ:**
```json
{
  "success": true,
  "keywords": "web development",
  "languages_filter": ["Python", "JavaScript"],
  "total_results": 5,
  "results": [
    {
      "type": "language",
      "name": "JavaScript",
      "display_name": "JavaScript",
      "properties": {...},
      "data": {...},
      "relevance": 85.5,
      "uri": "..."
    }
  ]
}
```

### Получение информации о конкретном языке

**GET** `/api/search/language/<name>`

Пример: `/api/search/language/Python`

**Ответ:**
```json
{
  "success": true,
  "language": {
    "language": "Python",
    "display_name": "Python",
    "data": {...},
    "publications": [...],
    "frameworks": [...]
  }
}
```

### Получение списка всех языков

**GET** `/api/search/languages`

**Ответ:**
```json
{
  "success": true,
  "total": 6,
  "languages": ["Python", "Java", "JavaScript", "C", "CPlusPlus", "CSharp"]
}
```

## Примеры поисковых запросов

1. **"web development"** - найдет языки и фреймворки для веб-разработки
2. **"object oriented"** - найдет языки с объектно-ориентированной парадигмой
3. **"beginner"** - найдет публикации для начинающих
4. **"Python"** - найдет всю информацию о Python
5. **"functional programming"** - найдет языки с функциональной парадигмой
6. **"game development"** - найдет языки используемые в разработке игр

## Источники данных

Система использует реальные данные из:
- **TIOBE Index** - рейтинги популярности языков
- **GitHub API** - статистика репозиториев и звезд
- **Stack Overflow API** - количество вопросов по языкам
- **Wikipedia** - дополнительная информация (опционально)

## Технические детали

- Поиск использует SPARQL запросы к RDF онтологии
- Релевантность вычисляется на основе количества совпадений ключевых слов
- Результаты сортируются по релевантности (от большей к меньшей)
- Дубликаты автоматически удаляются

## Модули

- `ontology_search.py` - основной модуль поиска с SPARQL запросами
- `improved_data_fetcher.py` - получение реальных данных из внешних источников
- `web_dashboard.py` - веб-интерфейс и API endpoints

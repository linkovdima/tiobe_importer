Реферат по дисциплине «Правовое регулирование в области IT»
Введение
В рамках выпускной квалификационной работы разрабатывается семантический веб-сервис для поиска информации о языках программирования на основе онтологии. Система агрегирует сведения из открытых источников, поддерживает обновление данных, поиск по ключевым словам с фильтрами, а также личный кабинет пользователя с сохранением найденных материалов и экспортом библиографии в формате BibTeX. При реализации такого проекта важно учитывать правовой режим используемых данных, лицензионные условия сторонних библиотек и API, а также риски информационной безопасности. Настоящий реферат рассматривает ключевые правовые аспекты разработки и применения данной системы.

1. Информация, используемая в ВКР
В ходе выполнения ВКР используются следующие категории информации:
1.	Программный код, созданный автором (модули на Python, веб-часть на Flask, шаблоны HTML/CSS/JavaScript, скрипты обновления и обработки данных).
2.	Онтологические данные в формате RDF/Turtle (структурированные сведения о языках программирования, свойствах, публикациях, фреймворках и связях между сущностями).
3.	Открытые данные и метрики из внешних источников (например, TIOBE, GitHub API, Stack Overflow и другие открытые веб-источники, используемые в рамках функционала проекта).
4.	Техническая и методическая документация (Flask, RDFLib, Requests, BeautifulSoup, Matplotlib, Schedule и др.).
Используемая в проекте информация относится преимущественно к общедоступным данным и техническим сведениям. Проект не ориентирован на сбор и обработку персональных данных физических лиц в объеме, требующем специального правового режима.

2. Источники информации и правовые основания использования
Все категории информации имеют правовые основания использования в рамках законодательства РФ и условий правообладателей.
1.	Собственный программный код
Используется на основании авторских прав разработчика в соответствии со ст. 1255 ГК РФ. Автору принадлежат исключительные права на созданные программные модули и архитектурные решения.
2.	Открытые данные из сети Интернет и API-платформ
Использование осуществляется в пределах правового режима общедоступной информации (Федеральный закон от 27.07.2006 № 149-ФЗ «Об информации, информационных технологиях и о защите информации») и при соблюдении пользовательских соглашений/Terms of Service соответствующих источников.
3.	Сторонние библиотеки и программные компоненты
Применяются на основе открытых лицензий (MIT, BSD, Apache 2.0 и др.) в соответствии со ст. 1235 ГК РФ о лицензионных договорах. При публикации проекта необходимо сохранять уведомления об авторстве и условия лицензий.
4.	Научные и учебные источники
Используются в учебно-исследовательских целях с соблюдением правил цитирования и ссылочного оформления (ст. 1274 ГК РФ — свободное использование произведений в информационных, научных и учебных целях в допустимых пределах).
Таким образом, при корректном соблюдении лицензионных условий и правил использования API правовой режим проекта является легитимным.

3. Пользователи результатов ВКР
Результаты ВКР предназначены для следующих категорий пользователей:
•	образовательная организация — для оценки результатов выпускной квалификационной работы;
•	научный руководитель и рецензенты — для экспертной оценки архитектуры, функциональности и применимости решения;
•	студенты и преподаватели IT-направлений — для поиска структурированных учебных материалов по языкам программирования;
•	разработчики и аналитики — для сравнительного анализа языков, источников и метрик популярности;
•	исследователи в области семантических технологий — как пример прикладного использования онтологий и семантического поиска.
Использование результатов допускается в учебных, исследовательских и аналитических целях. Коммерческое использование возможно при отдельном согласовании с правообладателем.

4. Права и обязанности пользователей, обеспечение их защиты
Права пользователей:
•	право на ознакомление с функциональностью системы и результатами поиска;
•	право на использование материалов в рамках допустимого цитирования и учебно-научных задач;
•	право на получение структурированной информации о языках программирования и связанных источниках;
•	право на использование личного кабинета для сохранения и экспорта выбранных материалов.
Обязанности пользователей:
•	соблюдать авторские права на код, интерфейс и структуру базы знаний;
•	не нарушать условия использования внешних API и веб-источников;
•	не использовать систему для незаконного массового сбора данных;
•	не распространять материалы ВКР и программный код вне правового режима использования.
Защита прав пользователей и автора обеспечивается за счет:
•	фиксации авторства в системе контроля версий;
•	лицензирования программного кода при публикации;
•	ограничения доступа к пользовательским функциям личного кабинета (аутентификация);
•	организационных мер по контролю использования внешних источников данных.
Права и обязанности сторон обеспечиваются сочетанием правовых, технических и организационных мер.

5. Угрозы безопасности в рамках ВКР, их значимость и методы противодействия
Несмотря на использование преимущественно открытых данных, при эксплуатации системы существуют риски.
Основные угрозы
Угроза	Значимость	Меры противодействия
Нарушение условий использования сторонних API и веб-источников	Средняя	Соблюдение лимитов запросов; использование официальных API; обработка ошибок и ограничений
Изменение структуры внешних сайтов (ошибки парсинга)	Средняя	Fallback-стратегии; тестовый режим; регулярная проверка и обновление парсеров
Неправомерное копирование программного кода	Средняя	Лицензирование; фиксация авторства в Git; указание условий использования
Компрометация учетных данных пользователя в личном кабинете	Средняя	Хеширование паролей; сессионная аутентификация; ограничение доступа к персональным данным кабинета
Утечка служебных ключей API (например, токена GitHub)	Высокая	Хранение секретов вне публичного репозитория; исключение конфигов с токенами из публикации
Недостоверность или устаревание внешних метрик	Низкая/средняя	Периодическое обновление данных; журналирование обновлений; указание времени актуализации
Для учебного проекта указанные меры являются достаточными для обеспечения базового уровня информационной безопасности и правовой корректности использования данных.

Заключение
Правовое сопровождение ВКР, посвященной разработке семантического веб-сервиса для поиска информации о языках программирования, требует учета авторских прав на программный код, лицензионных условий библиотек, правил использования внешних API и требований к безопасной эксплуатации веб-приложения. В проекте используются общедоступные данные и открытые программные компоненты, что при соблюдении установленных ограничений соответствует действующему правовому полю. Результаты работы имеют практическую ценность для образовательной и профессиональной аудитории, а выявленные угрозы безопасности могут быть нивелированы реализованными организационно-техническими мерами. Таким образом, разработка и применение системы правомерны и целесообразны в рамках целей ВКР.

Реферат по дисциплине «Правовое регулирование в области IT»
Введение
Для создания различных программных проектов в настоящее время необходимо обладать не только соответствующими техническими знаниями, но и пониманием правовых норм. В рамках выпускной квалификационной работы (ВКР) создаётся система для автоматизированной проверки контрагентов и анализа государственных закупок, использующая данные из внешних источников (ФНС, Росстат, ФССП, Роспатент, ЕИС закупки и др.). В связи с этим особое значение приобретает правовая оценка используемой информации, определение статуса пользователей и разработчика, а также анализ потенциальных угроз информационной безопасности. Настоящий реферат рассматривает ключевые правовые аспекты подготовки и реализации данной ВКР.
1. Информация, используемая в ВКР
В ходе выполнения ВКР используются следующие категории информации:
1.	Программный код, созданный автором (микросервисы на Python (Flask), модули парсеров, API-провайдеры, нейросетевая модель RuBERT, клиентская часть на HTML/CSS/JavaScript).
2.	Открытые данные государственных органов (ЕГРЮЛ, бухгалтерская отчётность ГИР БО, картотека арбитражных дел, реестр банкротств, данные ФССП, Роспатента и др.) и данные из государственных реестров, полученные через открытые API (dadata, of-data).
3.	Новостные материалы, получаемые через API-агрегаторы (Media Cloud, News API), содержащие публикации российских СМИ.
4.	Методическая и техническая документация (Flask, Redis, Docker, Transformers, RuBERT).
Используемая информация не содержит персональных данных в чувствительном объёме (агрегируются только общедоступные сведения о юридических лицах по ИНН) и относится к открытым общедоступным источникам.
2. Источники информации и правовые основания использования
Все категории информации имеют правовые основания использования в соответствии с законодательством РФ.
1.	Собственный программный код
Используется на основании авторских прав исполнителя (ст. 1255 ГК РФ). Автор обладает исключительными правами на разработанные модули и архитектурные решения.
2.	Данные государственных органов (ФНС, ЕГРЮЛ, ФССП и др.)
Основание — право на использование общедоступной информации в соответствии с Федеральным законом от 27.07.2006 № 149-ФЗ «Об информации, информационных технологиях и о защите информации». Данные являются открытыми и не ограниченными в доступе, если не содержат государственной или иной охраняемой тайны.
3.	Новостные материалы через API Media Cloud и News API
Использование осуществляется на основании публичных лицензий и условий предоставления API, а также в рамках права свободного цитирования (ст. 1274 ГК РФ) для научно-аналитических целей.
4.	Используемое ПО (Python, Flask, Redis, Docker, библиотека Transformers)
Применяется на основе открытых лицензий (MIT, Apache 2.0, BSD), что соответствует ст. 1235 ГК РФ о лицензионных договорах.
Таким образом, использование информации в ВКР соответствует действующему правовому полю и не нарушает авторских или иных прав третьих лиц.
3. Пользователи результатов ВКР
Результаты ВКР (информационно-аналитическая система) предназначены для следующих категорий пользователей:
•	Образовательная организация — для оценки квалификации студента.
•	Научный руководитель и рецензенты — для анализа выполненной работы.
•	Бизнес-аналитики, менеджеры, юристы, службы комплаенс — как целевая аудитория для проверки контрагентов.
•	Предприниматели и малый бизнес — для снижения рисков мошенничества и оценки надёжности партнёров.
•	IT-специалисты — в случае публикации архитектурных решений как пример микросервисной интеграции с государственными API.
Использование результатов допускается в аналитических и образовательных целях. Коммерческое применение возможно только с согласия автора как обладателя исключительных прав.
4. Права и обязанности пользователей, обеспечение их защиты
Права пользователей:
•	право на ознакомление с материалами работы:
•	право на использование материалов ВКР в рамках правомерного свободного использования, такого как цитирование или научные исследования;
•	право на получение достоверной информации о юридических лицах на основе агрегированных данных;
•	право на использование отчетов в рамках функционала системы;
Обязанности пользователей:
•	не использовать систему для сбора данных с целью нарушения законодательства (например, для незаконной разведки);
•	соблюдать авторские права на программный код и интерфейс;
•	не копировать и распространять материалы работы без согласия автора;
•	не осуществлять массовый автоматизированный парсинг помимо предусмотренных API;
•	соблюдать нормы действующего законодательства РФ об интеллектуальной собственности.
Защита прав пользователей и автора:
•	фиксация авторства — исходный код хранится в системе контроля версий (Git) с указанием дат и автора;
•	лицензирование — при публикации система может сопровождаться лицензией (например, CC BY-NC-SA), ограничивающей коммерческое использование;
•	отсутствие обработки персональных данных физических лиц — система оперирует только данными о юридических лицах (ИНН, ОГРН), что снижает риски нарушения ФЗ-152 «О персональных данных»;
•	техническая защита — кэширование в Redis не сохраняет персональные данные, все запросы к API аутентифицированы.
Права пользователей и автора обеспечиваются сочетанием правовых и организационных мер.
5. Угрозы безопасности в рамках ВКР, их значимость и методы противодействия
Несмотря на использование открытых данных, в системе существуют потенциальные угрозы.
Основные угрозы
Угроза	Значимость	Меры противодействия
Неправомерное копирование программного кода или модели RuBERT	Высокая	Хранение в закрытом репозитории; лицензирование; фиксация времени создания
Нарушение условий использования API (News API, Media Cloud, Dadata, of-data)	Средняя	Соблюдение лимитов запросов; использование официальных клиентских библиотек; аутентификация
Некорректная фильтрация новостей нейросетью, из-за которой последуют ложные репутационные риски	Средняя	Дообучение модели на расширенном датасете; ручная валидация выборки
Зависимость от сторонних API (временная недоступность)	Средняя	Кэширование в Redis (TTL 24 ч и больше); обработка ошибок с информативными сообщениями
Утечка данных при неправильной конфигурации Docker или Redis	Средняя	Использование изолированных контейнеров; отсутствие публичных портов для Redis; минимальные привилегии
Использование устаревших или нелицензионных библиотек	Низкая	Применение только официальных сборок (PyPI, Docker Hub); регулярное обновление
Большинство угроз имеют среднюю или низкую значимость в рамках образовательного проекта, а применяемые меры являются достаточными для обеспечения базовой информационной безопасности.
Заключение
Правовое обеспечение ВКР, посвящённой разработке информационно-аналитической системы для государственных закупок и оценки юридических лиц, требует комплексного анализа источников данных, соблюдения авторских прав, лицензионных условий API и государственных реестров. В работе используются только открытые и легально доступные данные, собственный программный код и лицензионное ПО. Результаты ориентированы на бизнес-пользователей, нуждающихся в проверке контрагентов, и могут применяться при соблюдении установленных правовых ограничений. Угрозы безопасности оцениваются как средние, а меры противодействия (кэширование, лицензирование, изоляция контейнеров, контроль API-запросов) признаны достаточными.

## Проверка результатов

После добавления проверьте:

```bash
python -c "from publication_manager import PublicationManager; pm = PublicationManager(); pubs = pm.get_publications_for_language('Python'); print(f'Найдено {len(pubs)} источников для Python'); [print(f\"  [{p['type']}] {p['title']}\") for p in pubs[:5]]"
```

Вы должны увидеть список добавленных источников.

## Использование в поиске

После добавления источники будут доступны в поиске:

1. Запустите веб-интерфейс:
   ```bash
   python web_dashboard.py
   ```

2. Откройте http://localhost:5000/search

3. Попробуйте поиск:
   - "fluent python" - найдет книгу
   - "documentation" - найдет документацию
   - "tutorial" - найдет туториалы

## Если что-то пошло не так

Если видите ошибки:
- Проверьте интернет соединение
- Убедитесь, что онтология загружается
- Попробуйте добавить источники для одного языка (вариант 1)
